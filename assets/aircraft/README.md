# Aircraft

Drop `aircraft-dakota.png` here: 1:1, 512 x 512 px, PNG with a transparent background.
A C-47 Dakota seen from directly above, **nose pointing right (east)**, centred, wingspan
about 90% of the width, no shadow and no text. The game flies it across the board at the
drop, turned to each run's heading, and prints its ground shadow from the same picture.
A missing file just means the drawn Dakota is used. Full spec and a prompt: ART-PROMPTS.md.
