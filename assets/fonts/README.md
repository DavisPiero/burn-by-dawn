# Fonts

WOFF2 faces for the game (ART-ASSETS.md §8). Only the ones listed in `FONTS` in
`src/render/theme.js` are loaded; the rest are options not taken.

| File | Used for | Licence |
|---|---|---|
| `ManlyMenBB.woff2`, `ManlyMenBB_bold.woff2` | Speech bubbles and the marker-pen notes (the lettering) | Blambot (Nate Piekos). **Confirm the licence allows web and game embedding for this use.** |
| `StardosStencil-Bold.woff2` | Headings, the results masthead: matches the title card | SIL Open Font License 1.1 (Google Fonts) |
| `ManlyMenBB_ital.woff2`, `StardosStencil-Regular.woff2`, `Marsh Stencil Regular.woff2` | Not used | — |
